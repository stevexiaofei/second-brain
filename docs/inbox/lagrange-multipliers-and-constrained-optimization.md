# 拉格朗日乘子与约束优化

## 一句话理解

当你要在“必须满足某个条件”的前提下，去找函数的最大值或最小值时，**拉格朗日乘子法**提供了一个把“约束”变成“方程组”的方法。

## 核心直觉

假设你想最大化/最小化目标函数 `f(x, y, ...)`，但变量不能随便选，必须满足约束 `g(x, y, ...) = c`。

在最优点上，通常会发生一件很重要的事：

> 目标函数的等高线，和约束曲线/曲面在那个点“刚好相切”。

这意味着两者的法向量平行，也就是：

```text
∇f = λ ∇g
```

这里的 `λ` 就是拉格朗日乘子。

## 为什么这成立

### 几何理解

- `∇f` 指向 `f` 增长最快的方向
- `∇g` 是约束曲线/曲面的法向量
- 如果在约束上已经到了最优点，那么你沿着约束允许的方向再移动一点，`f` 不能再继续变大或变小
- 所以 `f` 的增长方向不能再有“沿约束方向”的分量，只能和约束法向量对齐

### 代数理解

把约束看成“只能在某个曲面上活动”，最优点要求目标函数在所有可行方向上的变化率都为 0，于是导数条件会推成梯度平行。

## 单个等式约束的标准做法

如果要求在 `g(x, y, ...) = c` 下优化 `f(x, y, ...)`，做法是解下面这个系统：

```text
∇f = λ ∇g
g = c
```

展开后就是一组方程，连同约束一起求解所有未知数 `x, y, ..., λ`。

## 标准步骤

1. 写出目标函数 `f`
2. 写出约束 `g = c`
3. 构造方程 `∇f = λ ∇g`
4. 再加上约束本身
5. 解出候选点
6. 把候选点代回 `f`，比较大小，判断最大/最小

## 一个很重要的提醒

拉格朗日乘子法给你的是**候选点**，不是自动答案。

你还需要：
- 代回去比较目标函数值
- 检查边界情况
- 注意约束集合是否有多个分支

## 什么时候特别适合用

- 函数有等式约束
- 变量多，直接消元比较麻烦
- 想要一个统一的求解框架
- 多变量微积分里的经典极值问题

## 常见误区

### 1）把 `λ` 当成“答案”

不对。`λ` 只是辅助变量，真正要的是原变量的取值。

### 2）忘记同时满足约束方程

只解 `∇f = λ ∇g` 不够，必须连同 `g = c` 一起解。

### 3）忘记比较候选点

拉格朗日乘子法通常会给出多个点，必须比较目标函数值。

### 4）只适用于等式约束

经典形式主要处理等式约束；如果是“≤”或“≥”，通常还要考虑边界，或者进入更一般的 KKT 条件框架。

## 和“最优化”更大的关系

拉格朗日乘子法是优化理论的基础之一。它进一步发展后，会进入：
- 拉格朗日函数
- KKT 条件
- 对偶问题
- 凸优化

所以它不只是一个“做题技巧”，而是现代优化理论的重要起点。

## 记忆口诀

> **极值 + 约束 → 梯度平行 → 联立求解 → 回代比较**

## 你可以怎么记住它

如果你脑中有一条约束曲线，而你想在这条线上找最高点，最优点一定不是“随便碰到的点”，而是目标函数等高线和约束线“正好贴住”的点。
