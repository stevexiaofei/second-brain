# 📥 Inbox

这里是第二大脑的入口。任何突然想到的东西、看到的文章、论文、代码经验、问题、想法，都可以先放这里。

不要一开始就纠结分类。

## Rules

1. 先记录
2. 后整理
3. 不要因为分类而停止记录
4. 定期让 TRAE 帮助整理
