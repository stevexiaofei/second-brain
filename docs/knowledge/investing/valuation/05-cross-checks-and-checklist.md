# 交叉验证与实操检查清单

> 免责声明：本文是个人学习笔记，**不构成任何投资建议**。

## 一句话理解

单一估值方法只是"一个角度"，任何角度单独用都会骗人；**当绝对估值、相对估值、机会成本、隐含预期四个角度互相印证、指向同一个方向时，结论才可信**。本篇把前面所有笔记压缩成一张可执行的决策流程与检查清单——判断贵不贵的最终产品不是"一个目标价"，而是一份**写下假设、设好证伪条件、留足安全边际**的决策记录。

## 为什么需要"交叉"这一步

- 绝对估值说"便宜"、相对估值说"贵"、股债性价比说"市场整体不贵"——三者矛盾时，单信任何一方都是赌博。**矛盾本身就是最重要的信息**，它逼你找出哪个假设错了
- Damodaran 提醒：相对估值会传染市场情绪（整个板块泡沫里它永远"合理"），绝对估值会传染分析者自己的偏见（输入随便调）——**交叉 = 用各自的缺陷互相牵制**
- 估值不会让你变得理性（"一百万个旅鼠不会错"只是安慰）；只有流程化的证伪能部分对冲人性的偏

| 信号 | 判读 |
|---|---|
| 绝对、相对、机会成本都说便宜 | 最强信号；但仍要过"隐含预期"一关 |
| 绝对便宜、相对贵 | 可能你选的可比组不对，或你的增长假设比市场激进——查假设 |
| 相对便宜、绝对贵（DCF 说贵） | 可能整个板块都被高估，相对估值在"传染泡沫"——**以绝对估值为准** |
| 隐含增速需要我"不敢信"的水平才支撑现价 | 结论直接跳到"贵"，无需再辩 |

## 实操检查清单（可直接套用）

### 第 0 步：资格检查（不满足就放弃，省下所有时间）

- [ ] 我理解它的生意模式、钱从哪来、护城河是什么？（能力圈，[价值投资入门](../value-investing-intro.md)）
- [ ] 它属于哪类生意、处在生命周期哪一阶段？（决定后续选哪把尺子，[04](./04-multiples-by-business-type.md)）
- [ ] 财报有没有硬伤：现金流与利润背离、商誉/应收异常、审计非标？（[财报指南](../financial-statement-reading.md)）

### 第 1 步：绝对估值（[02](./02-absolute-valuation.md)）

- [ ] 确认近 3-5 年 FCF 质量（净利润 → FCF 转化率；是否靠赊销）
- [ ] 写悲观/中性/乐观三套假设（g、r、终值），**先写悲观**，得出 $[V_{\min}, V_{\max}]$
- [ ] 标注：现价 $P$ 处于区间的什么位置？$P \le V_{\min}$ 才有安全边际

### 第 2 步：相对估值（[03](./03-relative-multiples.md)）

- [ ] 主倍数口径正确（分子分母同属股权或同属公司；用扣非/TTM）
- [ ] 与"真可比"（同增速/同 ROE 桶）比，不是与整个行业比
- [ ] 配搭档变量：PB 配 ROE、PS 配毛利率、PE 配增速与盈利质量
- [ ] 历史分位：当前处于过去 5-10 年什么分位？**并检查基本面中枢与无风险利率是否已变**

### 第 3 步：机会成本与隐含预期（[01](./01-what-is-expensive.md)）

- [ ] 盈利收益率/FCF 收益率/股息率 vs 无风险利率（国债）：股权多赚的部分够不够补偿风险？
- [ ] 反推：现价隐含未来几年多少增速/ROE？我信吗？市场比我乐观还是悲观？

### 第 4 步：交叉与证伪（本篇）

- [ ] 三个独立信号是否对齐？矛盾点出在哪条假设？
- [ ] 反向一问："如果我是错的，最可能错在哪里？"（增长率假设、周期性误判、可比组、会计粉饰）
- [ ] 设置**证伪条件**：什么事实出现说明我的买入逻辑坏了？（e.g. 核心客户流失、监管转向、ROE 下穿阈值）

### 第 5 步：决策与记录

- [ ] 只有 $P \le V_{\min}$（安全边际足够）才买；否则记录"等待/放弃"，原因归档
- [ ] 买入即写决策日志：假设、目标区间、证伪条件、计划复查日期
- [ ] 仓位纪律：不用杠杆、分批、单一标的仓位上限（[价值投资入门](../value-investing-intro.md#入门行动清单)）

## 常见误区速查

| 误区 | 一句话澄清 |
|---|---|
| 低 P/E = 便宜 | 可能是价值陷阱：盈利/资产在恶化（[04](./04-multiples-by-business-type.md)） |
| 股价低 = 便宜 | 贵贱看倍数与价值，不看单价 |
| 跌得多 = 安全 | 下跌本身不创造安全边际，价值锚与现金流才创造 |
| 历史分位低 = 便宜 | 基本面中枢或利率变了，旧镜子失效 |
| 破净 = 便宜 | 要看 ROE 与资产质量（PB-ROE），破净的烂资产只会更烂 |
| 高 P/E = 贵 | 若增速与确定性足以支撑，可能仍便宜——看 PEG/隐含预期 |
| 所有方法都说便宜就能重仓 | 安全边际之上还有仓位纪律与"我会错"的谦卑 |

## 局限与诚实清单

- 估值是**艺术与纪律**，不是科学：不同人三情景会算出不同区间，这正常——正因如此，结论必须落在"区间 + 安全边际"，而不是"精确目标价"
- Damodaran：估值模型不会让你理性；它只是把你（带着偏见的）判断**显性化**。你不诚实，模型就帮你把偏见包装得更好
- 交叉验证能对冲"系统性泡沫"吗？不能完全——2000 年科网、2021 核心资产里，绝对估值（基于当时共识的乐观 DCF）同样会说"合理"。唯一靠得住的是**保守的悲观假设 + 仓位纪律 + 证伪条件**
- 我写的每个数字都带着我的盲区（能力圈外的高增长、被故事包装的会计、对周期的误判）——所以安全边际不是"加分项"，而是这套体系的**承重墙**

## My Understanding

- 这套流程对我最大的价值是**把"我觉得它便宜"翻译成"在什么假设下它便宜、哪些事实出现会推翻它"**——后者才是可以复盘、可以被市场证伪的东西
- "贵不贵"最终是一个**比较运算的结果**（我的保守估计 vs 市场定价），所以它的另一半永远是"市场在想什么"——只看公司不看定价（拿着好公司死扛泡沫）和只看定价不看公司（捡烟蒂式陷阱）是同一种错误的两面
- 下一步我要练习的：对 3-5 家公司完整走一遍本清单 + 决策日志，让"假设-证伪-复查"的循环转起来，而不是继续扩充理论框架
