# 相对估值：倍数工具箱

> 免责声明：本文是个人学习笔记，**不构成任何投资建议**。

## 一句话理解

相对估值把公司的价格"标准化"成一个可以跨公司比较的倍数（PE、PB、PS…），再拿它跟**同类公司**和**它自己的历史**比。倍数本身从不回答贵贱——**它只是把"贵不贵"压缩进了一个数字，真正的判断在于：你知不知道这个倍数背后的驱动因子，以及市场分布是什么样的。**

## 为什么重要

- 它是最主流的定价语言：Damodaran 估计约 85% 的股权研究用倍数下结论，因为简单、可交流、且天然贴着市场共识定价
- 它比绝对估值"公平"的地方：同类公司的市场定价里包含了大量你不知道的信息与情绪，相对比较等于借用了市场的集体智慧
- 它最大的危险也来自这里：**整个市场/板块都被高估时，相对估值会告诉你"跟着贵没问题"**——2000 年科网泡沫里，跟"同类"比永远合理，跟"内在价值"比早已荒谬

## 拆解任何倍数的四步（Damodaran 方法）

拿到任何倍数，先做四件事，否则数字就是噪音：

1. **定义（Define）**：口径一致吗？分子分母必须属于**同一类索取权**——股权价值/股本指标配股权类（P/E、P/B），企业价值/全公司指标配企业类（EV/EBITDA、EV/Sales）。用"市值/总利润"或"EV/净利润"这类混搭等于自欺
2. **描述（Describe）**：这个倍数的横截面分布长什么样？不知道行业典型区间，就无法判断一个 8 是低还是高
3. **分析（Analyze）**：什么基本面驱动它？每个倍数都是"增长、风险（折现率）、再投资需求/资本回报"三个变量的函数——所以**相同倍数可能对应完全不同质量的公司**
4. **应用（Apply）**：可比公司真的可比吗？比较时必须**控制已知差异**（增长率、ROE、杠杆、生命周期），否则比的是苹果和橙子

## 主倍数逐个拆

### P/E 市盈率（股权/利润）

| 项 | 内容 |
|---|---|
| 公式 | 市值 ÷ 净利润（或股价 ÷ EPS） |
| 通俗语言 | 按当前盈利，多少年回本 |
| 口径变体 | 静态（去年报）、TTM（近四季，最常用）、Forward（预测下年）、**扣非**（剔一次性损益，机构偏好） |
| 适用 | 盈利稳定、弱周期、现金流可预测的成熟公司（消费、医药、公用） |
| 最大坑 | ① 一次性损益/补贴虚增利润（用扣非）；② **周期股盈利在顶点时 PE 最低、最危险**；③ 亏损公司无意义 |

驱动公式（稳定增长，戈登模型倒推）：

$$
P/E = \frac{\text{派息率} \times (1+g)}{r - g}
$$

可见 P/E 由**派息率、增长率 g、要求回报率 r** 三个因子驱动——同样的 P/E=20，可以是"低增长高派息"也可以是"高增长低派息"，风险截然不同。

### P/B 市净率（股权/净资产）

| 项 | 内容 |
|---|---|
| 公式 | 市值 ÷ 归母净资产 |
| 通俗语言 | 为 1 块钱账面"家底"付多少钱 |
| 适用 | 金融、重资产、资源类；**必须与 ROE 连用** |
| 最大坑 | ① 轻资产公司（互联网/软件/品牌）净资产太小，P/B 无意义；② **破净 ≠ 便宜**：净资产可能被坏账/减值持续侵蚀 |

**P/B 与 ROE 的关系**（这是机构最爱用的个股框架）：

$$
\frac{P}{B} = f(\text{ROE}, \ r, \ g) \approx \frac{\text{ROE} - g}{r - g}
$$

- 逻辑：**P/B 应由 ROE 决定**。银行 A ROE 13% 而 P/B 0.9，银行 B ROE 8% 而 P/B 0.6——A 的绝对 P/B 更高，但放在"PB-ROE 平面"上 A 可能更便宜
- 实操：把同业公司画在 **ROE（横轴）– P/B（纵轴）** 散点图上，看谁**显著低于回归线**（同样的盈利能力却卖得更便宜），比单看 P/B 大小科学得多
- 反向警示：ROE 下滑期的"低 P/B"是价值陷阱温床（资产质量在恶化，账面净资产在缩水）

### P/S 市销率（股权/营收）

| 项 | 内容 |
|---|---|
| 公式 | 市值 ÷ 营收（或 EV ÷ 营收） |
| 通俗语言 | 为每 1 块钱收入付多少钱 |
| 适用 | 尚未盈利或利润微薄的高成长公司（早期科技、创新药、SaaS） |
| 最大坑 | 完全无视盈利能力：同样 P/S=8，一家毛利 70% 一家毛利 15%，贵贱天壤之别——**P/S 必须配毛利率与利润路径看** |

P/S 的驱动是"净利率 × 合理 PE"的复合体：$\frac{P}{S} = \frac{P}{E} \times \text{净利率}$。所以高毛利公司天然配得上高 P/S，低毛利公司的高 P/S 是幻觉。

### EV/EBITDA 企业价值倍数（全公司/经营利润）

| 项 | 内容 |
|---|---|
| 公式 | EV ÷ EBITDA；EV = 市值 + 净负债（有息负债 − 现金） |
| 通俗语言 | 抹掉资本结构与折旧政策后，"买下整个生意"对价经营利润的倍数 |
| 适用 | 高负债、高折旧、重资本开支行业（制造、电信、公用、周期），并购定价 |
| 最大坑 | ① 忽略资本开支强度（EBITDA 不含维持性 capex，烧钱的重资产公司会被高估）；② 金融行业不适用（EBITDA 无意义） |

为什么要用 EV：两家市值相同、利润相同的公司，一家背 500 亿净负债、一家有 500 亿净现金——买前者实际要付的钱远多于买后者。P/E 看不见这个差别，EV/EBITDA 能看见。

### PEG（市盈率相对盈利增长）

| 项 | 内容 |
|---|---|
| 公式 | P/E ÷ 预期净利润增速(%) |
| 通俗语言 | 每单位增速付多少倍 P/E；PEG<1 ≈ 成长没被充分定价 |
| 适用 | 盈利稳定增长（15%+）的成长股（Lynch 的 GARP 思路） |
| 最大坑 | ① 增速是"预测"，牛市中故事讲得越动听 PEG 越好看；② **周期股禁用**（增速在顶部自洽地很低）；③ 低增速稳定股 PEG 天然难看，不代表贵 |

### 股息率（股权/现金回报）

| 项 | 内容 |
|---|---|
| 公式 | 每股年度分红 ÷ 股价 |
| 通俗语言 | 不卖股票，每年拿到手多少"票息" |
| 适用 | 现金流稳定、分红政策稳定的成熟/公用事业类；高股息策略 |
| 最大坑 | ① 高股息率有时是"股价跌出来的"，先查分红可持续性（派息率是否 >100%）；② 高分红也可能意味着公司找不到再投资机会 |

股息率的优势在于它是**少数以现金形式落到你手里**的收益率，抗会计粉饰能力强，也是险资等长线资金定价银行股的重要锚（如某股份行 TTM 股息率 5.09% vs 10 年期国债 1.65-1.74%，利差超 3.4pp，构成其"红利逻辑"的估值基础）。

## 纵向比较：历史分位法

- 做法：看公司/指数当前 PE、PB 处于**过去 5-10 年自己历史区间的百分位**（<30% 偏低估、30-70% 中性、>70% 偏高估——经验参考线，非规则）
- 优点：剔除了"绝对倍数没意义"的问题——对同一家公司，纵向比最能反映"现在贵不贵"
- **两个失效前提（必须同时检查）**：
  1. 盈利质量/中枢变了：若 ROE 从 20% 掉到 8%，历史 PE 分位是"旧公司的尺子量新公司"
  2. 无风险利率变了：利率从 4% 降到 1.7%，全市场合理中枢上移，低分位不代表便宜、高分位也不代表贵
- 所以严谨的做法是 **PB-ROE 回归 + 历史分位双修**：先控制 ROE 看 P/B 相对位置（截面），再看该 P/B 距历史中枢的位置（纵向）

## 相对估值的三大结构性缺陷

1. **泡沫传染**：如果整个可比组都被高估（市场情绪），相对估值系统性地告诉你"不贵"——它没有"绝对对错"的锚
2. **可比性幻觉**：没有两家公司真正可比；"同行业"内部可能是完全不同的生意（同是"银行"，零售行与对公行 ROE/风险差异巨大）
3. **操纵空间**：分析师可以挑选利好自身的倍数定义、时间窗、可比组来支持任何结论——倍数缺少透明的假设暴露，比 DCF 更容易被操纵（Damodaran）

## My Understanding

- 相对估值是"市场共识的度量衡"，绝对估值是"我自己的度量衡"；两者必然打架——**打架的地方就是判断的起点**（见 [05](./05-cross-checks-and-checklist.md)）
- 倍数表里真正让我信任的不是单个数字，而是**分子分母口径对不对（Damodaran 命题一）、有没有配它的驱动变量（PB 配 ROE、PS 配毛利、PE 配增速与质量）**
- P/B 不能独立看、PE 不能跨周期看、PS 不能脱离毛利看、PEG 不能脱离预测可信度看——**每把尺子都有一个"必须一起看"的搭档变量**，这是比记公式重要得多的元规则

## Open Questions

- PB-ROE 框架对非金融（消费/制造）公司的适用边界在哪？它似乎更适合"资产能反映盈利能力"的行业
- 历史分位到底取多少年窗口？10 年太短（没覆盖完整牛熊）而 A 股历史又太短（很多公司上市不足 5 年）
- "控制差异后的可比"（如把同业按增速/ROE 分桶再比中位数）在小样本市场里会不会过度拟合？
