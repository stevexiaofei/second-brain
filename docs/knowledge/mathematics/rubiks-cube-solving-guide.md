# 魔方层先法实操指南

## 一句话理解

入门解法（层先法）不需要理解群论：它把"还原"拆成 7 个**互不破坏**的小目标，前 3 步靠理解，后 4 步靠 5–6 个**可重复执行的公式**。每个公式的本质都是"局部扰动 + 修复其余"（数学原理见 [魔方群的数学结构](./rubiks-cube-group-theory.md)）。

## 为什么先学这个

- 它是**最短的入门路径**：只需 5–6 个公式即可完成还原，1–3 分钟可达成
- 它建立"层"与"位置/朝向"分离的思维方式，是后续学 CFOP 的基础
- 理解公式在做什么（而不是死背），能显著降低记错率

## 记号约定（必须先记熟）

手持魔方，**面对你的那面称为 F**（Front），各面：

```
      U (Up)
L  F  R (Left / Front / Right)
      D (Down)
      B (Back，看不见的一面)
```

| 记号 | 含义 |
|---|---|
| `R` | 右面顺时针 90°（从右侧看） |
| `R'` | 右面逆时针 90°（撇号表示反向） |
| `R2` | 右面 180° |
| `U` / `U'` / `U2` | 上面，同理 |
| `F` / `F'` / `F2` | 前面，同理 |
| `L` / `D` / `B` | 左面 / 下面 / 后面，同理 |

口诀：**带 `'` 就是反向，`2` 就是转两下**。公式从左到右依次执行。

> 以下全部以**白色为底、黄色为顶**为例。若你的魔方配色不同（标准配色：白对黄、红对橙、蓝对绿），把颜色名替换即可。

## 七步总览

```
① 底层十字 → ② 底层角块 → ③ 第二层棱块
→ ④ 顶层十字 → ⑤ 顶面全黄 → ⑥ 顶层角块归位 → ⑦ 顶层棱块归位
```

前 3 步**靠观察和理解**，后 4 步**靠公式**。

## 第 1 步：底层十字（白色十字）

**目标**：底面出现白色十字，且四条侧面棱的颜色与相邻中心块对齐（这一步的对齐决定后面是否全乱）。

**做法（无需公式）**：

1. 找到 4 个含白色的棱块
2. 逐个把白棱先转到黄色中心周围（顶面），形似"花瓣"
3. **对齐侧面颜色**后，把该面转 180°，让白棱落到白色中心旁边
4. 重复 4 次

**要点**：
- 关键不是"让白色下来"，而是**侧面颜色必须对齐侧面中心**
- 这一步完全可以用直觉解决，**不要背公式**

## 第 2 步：底层角块（完成第一层）

**目标**：4 个含白色的角块归位，第一层完整。

**做法**：把目标角块转到它**目标位置的正上方**（例如白-红-蓝角块，要放到红面与蓝面之间的底角），再根据白色朝向选择：

| 白色朝向 | 公式 |
|---|---|
| 朝右 | `R U R' U'`（重复执行直到归位） |
| 朝前（面向你） | `U R U' R'` |
| 朝上 | `R U2 R' U' R U R'` |

**原理**：`R U R' U'` 是交换子 $[R,U]$，它把角块在几个位置间做 3-循环，同时基本不动已还原的部分。因此**重复执行必然归位**（最多几次）。

**常见错误**：没把角块转到目标位正上方就开始执行 → 会把已完成的第一层转乱。

## 第 3 步：第二层棱块

**目标**：补齐中间层 4 个棱块。

**做法**：

1. 在**顶层**找一个**不含黄色**的棱块
2. 转动顶层，使其**侧面颜色与同色中心块对齐**，形成一个倒 T 形
3. 判断它应该去左边还是右边，执行对应公式

| 去向 | 公式 |
|---|---|
| 插入右侧 | `U R U' R' U' F' U F` |
| 插入左侧 | `U' L' U L U F U' F'` |

**特殊情况**：要用的棱块已经在第二层，但位置或朝向错了——用上面任一公式把它"顶"到顶层，再按正常流程处理。

**原理**：公式前半段把顶层的棱块送进中层，后半段修复被牵连的块（共轭结构）。

## 第 4 步：顶层十字（黄色十字）

**目标**：顶面出现黄色十字（**不要求**角块）。

此时顶面黄色棱只有 3 种形态：**一点**、**一条线**、**一个 L（倒 L）**。

**公式**：`F R U R' U' F'`

**用法**：
- **点** → 执行一次 → 变线 → 摆好方向再执行 → 十字
- **线** → 让线**横向**对着自己 → 执行一次 → 十字
- **L** → 摆成"左上"形（开口朝右下方）→ 执行一次 → 十字

**要点**：公式首尾是 `F ... F'`（共轭），所以它只改变顶层的朝向关系，不破坏已完成的两层。

## 第 5 步：顶面全黄（角块朝向）

**目标**：整个顶面变成黄色。

**公式（Sune / 小鱼公式）**：`R U R' U R U2 R'`

**用法**：
1. 观察顶面黄色分布，找到唯一一个**已经朝上**的黄色角块（"鱼头"）
2. 把鱼头摆到**左后方**（不同教程略有差异，实践确认）
3. 执行公式；若未全黄，重复 1–2 次

**原理**：Sune 属于 OLL（顶面朝向）的基础 case，本质仍是交换子的组合，只改变顶面角块的朝向。

## 第 6 步：顶层角块归位

**目标**：4 个顶角都到**正确位置**（朝向可能还没对，但位置对）。

**做法**：先找一个"位置已经正确"的角块（颜色与所在三面匹配），把它固定，然后：

**公式**：`U R U' L' U R' U' L`

它实现**三个角块的循环置换**。若当前没有任何角块在正确位置，先执行一次，就会有一个到位。

## 第 7 步：顶层棱块归位（完成）

**目标**：4 个棱块归位，魔方还原。

**公式（U-perm）**：`R U' R U R U R U' R' U' R2`

它实现**三个棱块的循环置换**。执行 1–2 次即可完成。

## 完整流程速查表

| 步骤 | 目标 | 公式 |
|---|---|---|
| 1 | 底层十字 | 无（靠理解） |
| 2 | 底层角块 | `R U R' U'` / `U R U' R'` / `R U2 R' U' R U R'` |
| 3 | 第二层棱块 | `U R U' R' U' F' U F`（右）/ `U' L' U L U F U' F'`（左） |
| 4 | 顶层十字 | `F R U R' U' F'` |
| 5 | 顶面全黄 | `R U R' U R U2 R'` |
| 6 | 顶角归位 | `U R U' L' U R' U' L` |
| 7 | 顶棱归位 | `R U' R U R U R U' R' U' R2` |

## 从入门到进阶

| 阶段 | 方法 | 公式量 | 大致水平 |
|---|---|---|---|
| 入门 | 层先法（本文） | 约 6 个 | 1–3 分钟 |
| 进阶 | **CFOP**（Fridrich） | 119（F2L 41 + OLL 57 + PLL 21） | 10–20 秒 |
| 其他 | Roux、ZZ | 各有体系 | 顶级选手使用 |

**CFOP 四阶段**：

1. **C**ross：底层十字（可优化到 8 步内）
2. **F**2L：**同时**插入角块与棱块（41 个 case，最大瓶颈，收益最高）
3. **O**LL：顶面朝向（57 个）
4. **P**LL：顶层排列（21 个）

**学习顺序建议**：入门法练到 1 分钟以内 → 先学 F2L（理解"配对 + 插入"，别死背 41 个）→ 再补 OLL/PLL 的常用 case。

## 练习要点与常见卡点

1. **打乱要随机**：只用 `R U R' U'` 之类的固定循环打乱，会得到过于简单的状态
2. **每步只盯一个目标**，做完立刻检查第一层有没有被破坏
3. **记"效果"而不是"字母"**：例如记"这个公式让 3 个角块循环"，比背 `U R U' L' U R' U' L` 可靠
4. **最大的卡点：起始朝向摆错**。公式效果是确定的，但必须把魔方摆到公式要求的位置/朝向，否则结果不对
5. **公式本身不会"转坏"魔方**：只要严格按顺序执行，它一定只做它该做的事（这就是 [原理笔记](./rubiks-cube-group-theory.md) 里支撑集与共轭的结论）
6. **工具**：J Perm 的教学视频、csTimer（计时）、在线求解器（可用来验证"某公式的效果"）

## 我的理解

- 层先法的设计哲学是**分层 + 逐层锁定**：每完成一层就把它当作"不可动的既成事实"，后续公式保证不破坏它。这和工程里的"冻结已验收模块"是同一思路
- 前 3 步与后 4 步的认知负荷完全不同：前者是**空间推理**（可理解），后者是**符号执行**（可记忆）。理解这个区别能帮助安排练习
- 真正阻碍入门的不是公式数量，而是**朝向摆放**：多数"失败"其实不是转错了，而是起点错了
