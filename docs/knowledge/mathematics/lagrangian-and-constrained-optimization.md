# 拉格朗日乘子与约束优化

## 一句话理解

当你要在**满足约束条件**的前提下，去找函数的最大值或最小值时，拉格朗日乘子法把“在约束上找极值”转成“解一组方程”。

## 先建立直觉

如果目标函数是 `f(x, y, ...)`，约束是 `g(x, y, ...) = c`，那么可行点只能落在一条曲线或一个曲面上。

在最优点上，通常会发生：

> 目标函数的等高线与约束曲线/曲面刚好相切。

相切意味着两个法向量平行，所以：

```text
∇f = λ ∇g
```

这里的 `λ` 就是拉格朗日乘子。

## 为什么这个条件成立

### 几何上看

- `∇f` 指向目标函数上升最快的方向
- `∇g` 是约束曲线/曲面的法向量
- 在约束上走一步，必须留在可行集合里
- 如果已经是最优点，那么沿着可行方向再动，`f` 不能再继续增加或减少
- 所以 `f` 的梯度只能和约束的法向量对齐

### 代数上看

可行方向上的变化率必须为 0，于是目标函数梯度落在约束梯度张成的方向上，最终推出梯度平行。

## 单个等式约束的标准形式

若要求在 `g(x, y, ...) = c` 下优化 `f(x, y, ...)`，就解：

```text
∇f = λ ∇g
g = c
```

未知数包括原变量和 `λ`。

## 标准步骤

1. 写出目标函数 `f`
2. 写出约束 `g = c`
3. 构造方程 `∇f = λ ∇g`
4. 加上约束方程本身
5. 解出所有候选点
6. 把候选点代回 `f`，比较大小，判断最大值和最小值

## 一个很重要的提醒

拉格朗日乘子法只给出**候选点**，不是最终答案。

你还需要：
- 回代比较函数值
- 检查边界
- 看约束是否有多个分支
- 注意是否存在不可导点或特殊点

## 一个简单例子

假设要在约束 `x^2 + y^2 = 1` 上，让 `f(x, y) = x + y` 取得极值。

做法是：
- `∇f = (1, 1)`
- `∇g = (2x, 2y)`
- 解 ` (1, 1) = λ (2x, 2y)`
- 再结合 `x^2 + y^2 = 1`

这类题的本质就是：**先找“相切点”，再比大小**。

## 什么时候特别适合用

- 有等式约束
- 变量比较多，直接消元麻烦
- 想统一处理多变量极值问题
- 想理解更一般的优化理论

## 常见误区

### 1）把 `λ` 当答案

不对。`λ` 只是辅助变量，真正要的是原变量的解。

### 2）忘记约束方程

只解 `∇f = λ ∇g` 不够，必须连同 `g = c` 一起解。

### 3）忘记比较候选点

拉格朗日乘子法通常会有多个候选点，要比较目标函数值。

### 4）误以为只适用于等式约束以外的所有情形

经典拉格朗日乘子法主要处理等式约束；不等式约束一般要进入更一般的 **KKT 条件**。

## 拉格朗日函数是什么

把目标函数和约束合成一个函数：

```text
L(x, λ) = f(x) - λ (g(x) - c)
```

然后对变量和乘子分别求导。

它的意义是：
- 用一个统一的对象把目标和约束绑在一起
- 便于推广到更复杂的优化问题

## 和 KKT 的关系

拉格朗日乘子法可以看成 KKT 的基础版本。

当约束变成：
- 等式约束
- 不等式约束
- 互补松弛条件

就会进入 KKT 框架。

所以可以把它理解成：

> 拉格朗日乘子法 = 约束优化的入门版
> KKT = 更一般的正式版本

## 一个记忆口诀

> **极值 + 约束 → 梯度平行 → 联立求解 → 回代比较**

## 学习时最该抓住的东西

1. 约束把可行域限制成一条曲线或一个曲面
2. 最优点上，目标函数和约束通常相切
3. 相切对应梯度平行
4. `λ` 是把约束吸收到方程里的辅助变量
5. 求出来以后还要比较候选点
