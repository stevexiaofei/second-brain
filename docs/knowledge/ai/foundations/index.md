# AI Foundations

这里沉淀模型、算法和训练方法的基础知识。专题按问题域组织，论文笔记用于提供证据与演进脉络，概念笔记用于形成可复用理解。

## Topics

- [Reinforcement Learning](./reinforcement-learning/) — 价值函数、Bellman 方程和策略优化
- [Diffusion Models](./diffusion/) — 扩散过程、训练目标与采样
- [Reasoning & Inference](./reasoning/) — 推理提示、搜索、验证和自我改进

## 组织原则

- 一个稳定概念优先形成一篇原子笔记。
- 一篇论文笔记记录问题、方法、证据、限制和个人理解。
- 多论文综述只承担路线图与比较职责，成熟后再拆出独立论文笔记。
