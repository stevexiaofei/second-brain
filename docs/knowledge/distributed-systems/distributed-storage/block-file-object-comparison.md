# 块存储、文件存储与对象存储对比

## 一句话理解

这三种存储不是“谁更高级”，而是**语义不同、抽象层不同、适合的工作负载不同**。

- 块存储：给你一块“裸硬盘”
- 文件存储：给你“共享文件系统”
- 对象存储：给你“海量键值仓库”

## 先用一句人话区分

### 块存储

像一块插在机器上的盘。你看到的是一串扇区或块，通常需要自己在上面再格式化文件系统。

### 文件存储

像一个大家一起用的共享文件夹。你可以直接按路径读写文件。

### 对象存储

像一个超大仓库，你通过名字去找对象，不太关心它在底层哪台机器上。

## 对比总表

| 维度 | 块存储 | 文件存储 | 对象存储 |
|---|---|---|---|
| 最小操作单元 | 块 / 扇区 | 文件 / 目录 | 对象 / key |
| 访问方式 | 读块、写块 | path + POSIX 操作 | HTTP / S3 API |
| 典型语义 | 裸设备 | 共享文件系统 | 扁平命名空间 |
| 是否直接支持目录 | 不支持 | 支持 | 通常只是前缀 |
| 是否支持 append | 交给上层文件系统 | 支持 | 通常不擅长 |
| 是否支持 rename | 交给上层文件系统 | 支持 | 通常是拷贝+删除 |
| 延迟 | 最低 | 中等 | 通常最高 |
| 扩展性 | 中等 | 中等到较强 | 最强 |
| 成本 | 高 | 中 | 低 |
| 典型场景 | 数据库、虚机盘 | 共享工作区、训练文件 | 数据湖、备份、归档 |

## 块存储到底是什么

块存储给上层提供的是“原始块设备”。

上层通常会自己再做：
- 文件系统
- RAID
- 数据库页管理
- 日志结构存储

### 块存储的特点

- 延迟低
- 随机读写能力强
- 适合高 IOPS 场景
- 但语义最少，应用要自己管理很多东西

### 常见使用场景

- 数据库数据盘
- 虚拟机镜像盘
- 操作系统盘
- 需要低延迟随机 IO 的应用

## 文件存储到底是什么

文件存储提供的是“共享文件系统”。

你可以直接：
- `open`
- `read`
- `write`
- `stat`
- `mkdir`
- `rename`

### 文件存储的特点

- 使用方便
- POSIX 语义直观
- 多个客户端可同时访问
- 但元数据压力大，扩展性往往不如对象存储

### 常见使用场景

- 多机共享工作目录
- HPC 作业输入输出
- 训练集读取
- 编译缓存

## 对象存储到底是什么

对象存储提供的是“以 key 访问 object”。

对象一般包含：
- 数据本体
- 元数据
- 版本信息
- 校验信息

### 对象存储的特点

- 最容易水平扩展
- 适合海量数据
- 成本低
- 但不擅长频繁修改同一对象

### 常见使用场景

- 数据湖
- 归档
- 日志
- 图片/视频/训练数据集
- 跨地域备份

## 为什么它们不能互相直接替代

### 块存储不能很好替代文件存储

因为块存储没有现成的目录、权限、路径语义。

### 文件存储不能很好替代对象存储

因为文件系统元数据和锁机制在超大规模下会更复杂、更贵。

### 对象存储不能很好替代块存储

因为对象存储不擅长原地小更新、低延迟随机 IO。

## 一个非常实用的判断方法

### 你问自己三个问题

1. **我要的是低延迟随机读写吗？**
   - 是 → 块存储

2. **我要共享目录和文件语义吗？**
   - 是 → 文件存储

3. **我要海量扩展和低成本吗？**
   - 是 → 对象存储

## 语义差异带来的真实后果

### rename

- 文件系统：通常是原子语义的一部分
- 对象存储：很多情况下不是“原地改名”，而是复制后删除

### append

- 文件系统：可以追加
- 对象存储：通常更适合整体重写，而不是原地追加

### list / glob

- 文件系统：天然支持目录遍历
- 对象存储：list 可能很贵，而且目录只是前缀

## 为什么训练场景经常同时需要三者

AI 训练常见分层是：

- 对象存储：放原始数据和归档数据
- 文件存储：放训练共享数据和中间结果
- 块存储：放数据库、索引、缓存、临时高性能工作区

这不是重复建设，而是让不同层各做自己最擅长的事。

## 初学者最容易犯的错

### 1）把对象存储当成普通文件系统用

会遇到 rename、append、小文件、list 等问题。

### 2）把文件存储当成“无限可扩展的共享盘”

元数据和锁会先出问题。

### 3）把块存储当成“最通用的方案”

它语义最少，很多上层复杂性会转移给应用。

## 结论

记住这句话就够用了：

> 块存储卖的是性能，文件存储卖的是语义，对象存储卖的是规模和成本。
